# Spar-Speiseplan

Web-App, die aus Budget, Personen, Wünschen und Küchengeräten einen Speiseplan mit Einkaufsliste macht.

- Keine Installation und kein Build nötig: `index.html`, `style.css`, `app.js`, `daten.js`.
- Alles läuft im Browser. Einstellungen, Plan und eigene Preise bleiben auf dem Gerät.
- Preise sind grobe Schätzungen für ganze Packungen (Aldi, Penny, Edeka) und im Einkauf anpassbar.
- Fotos sind Symbolfotos von [TheMealDB](https://www.themealdb.com). Die Rezepte stehen in `daten.js`.
